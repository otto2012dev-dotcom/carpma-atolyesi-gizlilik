Privacy Policy

Multiplication Workshop — Effective date: September 1, 2026 · Last updated: September 24, 2026

In short: Multiplication Workshop does not collect, store or share any personal data. The game works completely offline and contains no ads.

1. Data Collected

Multiplication Workshop does not collect any personal data. The game does not access or ask for a name, email address, location, photos, contacts, device identifier or any other personal information.

2. Internet Connection

The game works completely offline. It does not send any data to a server and does not receive any data from a server. It does not need an internet connection.

3. Data Stored on the Device

The game stores only the following information in your device's own storage:

  • Music, sound effect and language preferences (on/off, English/Turkish)
  • Best scores in the game and the medals and balloons earned
  • Daily challenge progress and day streak
  • How many questions were asked for each number and how many were answered correctly (for the Number Map in the game)

This information never leaves the device, is not shared with anyone and is completely removed when the app is deleted.

4. Ads and Third Parties

The game contains no ads. No third-party services (SDKs) are used for analytics, tracking or advertising.

5. Children's Privacy

Multiplication Workshop is an educational game for children. Because no data is collected, no information is collected from children either. The game complies with laws that protect children's privacy (for example COPPA and GDPR-K).

6. Purchase

The game is bought once through the App Store or Google Play. Payments are handled entirely by Apple or Google; as the developer, we have no access to your payment information in any way.

7. Changes

If this privacy policy changes, the current version will be published on this page.
